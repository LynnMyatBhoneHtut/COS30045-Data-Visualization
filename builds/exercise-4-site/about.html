About

How this hub was put together

This is Site A: an independent clone of the Exercise 0.2 energy website that runs the D3 code from Exercises 4.3 to 4.7 inside that site's layout, navigation and colours. The original exercise folders are untouched; everything here lives in builds/exercise-4-site/.

The project

Scope and intent

Where it came from

The layout, navigation, stylesheet, logo, footer and FAQ accordion are cloned from Exercise 0.2/energy-webpage-v1. The charts and their CSV come from Exercise 4/Exercise 4.3 to 4.7.

What changed

Each exercise draws into its own container and runs in its own function scope, because five of them now share one page. Colours come from the theme instead of "blue", the debug borders became a dashed outline, and labels use the site's fonts.

What stayed the same

Every scale, data join, position and size, the CSV path, the row conversion and the console logging are the original code. Lines that differ are marked HUB: in each file.

Run it locally

d3.csv() fetches its file over HTTP, so the hub needs a local web server rather than a double-click. From the repository root: 

python3 -m http.server 8000

Then open http://localhost:8000/builds/exercise-4-site/. Serving from the repository root also keeps the "Open original" links and the link to the standalone Exercise 4.1 working.
