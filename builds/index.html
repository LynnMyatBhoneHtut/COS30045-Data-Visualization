Running and hosting

The charts load CSV files with d3.csv(), which needs a web server. From the repository root: 

python3 -m http.server 8000

Then open http://localhost:8000/builds/. Each hub folder is self-contained, so it can also be hosted on its own; the "Open original" links and the Exercise 4.1 link only work when the whole repository is served, as it is on GitHub Pages.
