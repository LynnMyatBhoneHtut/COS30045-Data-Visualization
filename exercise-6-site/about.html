About

How this hub was put together

This is Site C: an independent clone of the Exercise 0.2 energy website that runs the Exercise 6 histogram, filters, scatterplot and tooltip inside that site's layout, navigation and colours. The original Exercise 6 folder is untouched; everything here lives in builds/exercise-6-site/.

The project

Scope and intent

Where it came from

The layout, navigation, stylesheet, logo, footer and FAQ accordion are cloned from Exercise 0.2/energy-webpage-v1. The charts, interactions and CSV come from Exercise 6. The README there groups the work as 6.1 (histogram with filtering) and 6.2 (scatterplot with tooltips); the code comments number the four parts 6.1 to 6.4, and this hub follows the code.

What changed

The histogram bars use the theme's slate, the scatterplot's colours are three checked theme hues, the tooltip looks like the site's read-out panel, and the filter buttons look like the navigation's active state. The two charts sit in tabs.

What stayed the same

Sizes, margins, scales, bins, the filter logic, the 500 ms transition, the tooltip's position and text, the CSV path and the script order are the original code. histogram.js and load-data.js are copied unchanged; other differences are marked HUB:.

Run it locally

d3.csv() fetches its file over HTTP, so the hub needs a local web server rather than a double-click. From the repository root: 

python3 -m http.server 8000

Then open http://localhost:8000/builds/exercise-6-site/. Serving from the repository root also keeps the "Open original" links working.
