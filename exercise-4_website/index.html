Understanding the energy use of household televisions in Australia. Exercises 4.3 to 4.7 build a D3 bar chart of TV models by brand, one step at a time.

Exercise 4.3

D3 setup

D3 is loaded into the page, then creates a responsive SVG canvas (viewBox="0 0 1200 1600") and draws one hard-coded test bar to show that everything works.

Exercise 4.4

Load data from CSV

d3.csv() reads tvBrandCount.csv and turns each count into a number. The data is checked and sorted, then written to the console, so the canvas stays empty in this step.

Exercise 4.5

D3 binding and drawing with data

The data is bound to rectangles, one bar per brand, sorted from most to fewest models. Each bar's width is its count in pixels and its position comes from its place in the list.

Exercise 4.6

Scaling charts

A linear scale turns each count into a bar width and a band scale spaces the brands evenly, so all 25 bars fit a smaller 500 × 600 canvas.

Exercise 4.7

Adding labels

Each bar is grouped with its brand name and its number of models in a <g> element. Samsung lists the most models (1,096), followed by Kogan (788) and LG (677).
