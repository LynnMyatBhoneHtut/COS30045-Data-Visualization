Key code · js/bar-chart.js 
const xScale = d3.scaleBand()
    .domain(data.map(d => d.Screen_Tech))
    .range([0, innerWidth])
    .padding(0.1);

const yScale = d3.scaleLinear()
    // a little headroom above the tallest bar so its value label fits
    .domain([0, d3.max(data, d => d.Energy_Consumption) * 1.07])
    .range([innerHeight, 0]);

const bottomAxis = d3.axisBottom(xScale)
    .tickSize(0)
    .tickPadding(12)
    .tickFormat(d => d.toUpperCase());   // lcd -> LCD

// ...bars
    .attr("height", d => innerHeight - yScale(d.Energy_Consumption))
    .attr("fill", THEME.teal);             // was "green"

Key code · js/line-chart.js 
const xScale = d3.scaleLinear()
    .domain(d3.extent(data, d => d.year))   // [1998, 2024]
    .range([0, innerWidth]);

const yScale = d3.scaleLinear()
    .domain([0, d3.max(data, d => d.averagePrice)])
    .range([innerHeight, 0])
    .nice();

const lineGenerator = d3.line()
    .x(d => xScale(d.year))
    .y(d => yScale(d.averagePrice));

innerChart.append("path")
    .attr("d", lineGenerator(data))
    .attr("fill", "none")
    .attr("stroke", lineColour);   // THEME.teal, was "#000"

Key code · js/donut-chart.js 
const color = d3.scaleOrdinal()
    .domain(data.map(d => d.Screensize_Category))
    .range(data.map(d => sizeShade[d.Screensize_Category] || THEME.teal));   // was d3.schemeSet2

const pie = d3.pie()
    .value(d => d.Count)
    .sort(null);   // keep the original data order

const arcGenerator = d3.arc()
    .innerRadius(radius * 0.6)
    .outerRadius(radius * 1);

innerChart.selectAll("path")
    .data(pie(data))
    .join("path")
    .attr("d", arcGenerator)
    .attr("fill", d => color(d.data.Screensize_Category));

Reading the charts

FAQ

The y domain runs to the largest value × 1.07. That 7% headroom keeps the value label above the tallest bar inside the SVG instead of cutting it off at the top edge.

Years are continuous: the distance between two points on the line should match the time between them. The bar chart's screen technologies are separate categories with no order, which is what a band scale is for.

d3.pie() gives each row a start and end angle in proportion to its Count, and .sort(null) keeps the CSV's order. d3.arc() then turns each pair of angles into a path between the inner radius (60% of the radius) and the outer radius, which is what leaves the hole in the middle.

Screen size has an order (small, medium, large), so a light to dark ramp of one hue shows that order at a glance. The original used d3.schemeSet2, a palette for unrelated categories. The chart still uses d3.scaleOrdinal() with the same domain; only the colours in its range changed.
