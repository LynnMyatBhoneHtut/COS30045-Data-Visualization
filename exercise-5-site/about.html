About

How this hub was put together

This is Site B: an independent clone of the Exercise 0.2 energy website that runs the three Exercise 5 charts inside that site's layout, navigation and colours. The original Exercise 5 folder is untouched; everything here lives in exercise-5-site/.

The project

Scope and intent

Where it came from

The layout, navigation, stylesheet, logo, footer and FAQ accordion are cloned from Exercise 0.2/energy-webpage-v1. The chart code and the three CSV files come from Exercise 5.

What changed

The bars, line and axes take the theme's colours and fonts, the points gain a thin ring, and the donut's categorical palette becomes one teal ramp because screen size is ordered. Each chart sits in its own tab.

What stayed the same

Margins, viewBoxes, scales, axes, the line and pie generators, the CSV paths and row conversions are the original code, and load-data.js is copied unchanged. Lines that differ are marked HUB:.

Run it locally

d3.csv() fetches its files over HTTP, so the hub needs a local web server rather than a double-click. From the repository root: 

python3 -m http.server 8000

Then open http://localhost:8000/exercise-5-site/. Serving from the repository root also keeps the "Open original" links working.
